# 5 ELEMENT — responsive GitHub Pages build

`index.html` полностью автономный: изображение, стили и анимации встроены внутрь.

Адаптация:
- телефоны: полноэкранный портретный режим;
- планшеты: композиция масштабируется без поломки зон клика;
- ноутбуки и ПК: основная композиция занимает всю доступную высоту, а боковые области заполняются мягким фоновым изображением вместо пустых полос;
- landscape: сохраняются пропорции исходной композиции;
- учтены safe-area на мобильных устройствах.

GitHub Pages:
1. Загрузите `index.html`, `README.md` и при необходимости `CNAME.example` в корень репозитория.
2. Settings → Pages → Deploy from a branch → main → /(root).
3. Для домена `5element.cc` после запуска укажите его в Settings → Pages → Custom domain.
4. Затем настройте DNS у регистратора и после успешной проверки включите Enforce HTTPS.

`CNAME.example` не влияет на первый запуск. Когда будете подключать домен, переименуйте его в `CNAME`.
