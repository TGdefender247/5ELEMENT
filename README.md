# 5 ELEMENT — GitHub Pages

Готовая автономная версия сайта.

## Что внутри

- `index.html` — весь сайт в одном файле: изображение, стили, анимации и адаптив.
- `CNAME.example` — заготовка для домена `5element.cc`.

## Адаптация

Сайт автоматически подстраивается под:
- телефоны;
- планшеты;
- ноутбуки;
- большие мониторы;
- вертикальную и горизонтальную ориентацию.

На телефоне основная композиция занимает всю ширину.
На широком экране композиция сохраняет правильные пропорции 9:16 и занимает всю высоту, а свободное пространство заполняется мягким фоном из того же изображения.

## GitHub Pages

1. Загрузить `index.html`, `README.md` и `CNAME.example` в корень репозитория.
2. Открыть `Settings → Pages`.
3. Выбрать `Deploy from a branch`.
4. Branch: `main`.
5. Folder: `/(root)`.
6. Нажать `Save`.

## Домен 5element.cc

После проверки сайта на адресе GitHub Pages:
1. `Settings → Pages → Custom domain`.
2. Указать `5element.cc`.
3. Настроить DNS у регистратора.
4. После проверки включить `Enforce HTTPS`.

`CNAME.example` не активирует домен автоматически. Когда домен будет готов, переименуйте его в `CNAME`.
